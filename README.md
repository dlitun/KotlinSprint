# KotlinSprint

**KotlinSprint** — учебный репозиторий для изучения языка **Kotlin с нуля**.  
Проект охватывает базовые и ключевые концепции языка и ориентирован на формирование прочного фундамента для Android-разработки.

---

## 📚 Структура курса

### Основы языка
1. Переменные и типы данных  
2. Арифметические операции  
3. Работа со строками  
4. Операторы сравнения  
5. Условные конструкции `if / else / when`  

### Управление потоком выполнения
6. Циклы `while`, `do while`  
7. Цикл `for`, диапазоны  

### Коллекции и данные
8. Массивы  
9. Списки  

### Функции и ООП
10. Функции  
11. Классы и свойства  
12. Конструкторы, `init`  
13. Null Safety, NPE  
14. Наследование  
15. Интерфейсы и абстракция  
16. Инкапсуляция  
17. Сеттеры и геттеры  
18. Полиморфизм  

### Расширенные возможности Kotlin
19. `enum`, `companion object`  
20. Лямбда-выражения  
21. Extension-функции  
22. `data class`

---

## 🧠 Формат обучения

- **22 урока по Kotlin**
- **220 тестовых вопросов** (по каждому уроку)
- **120 практических задач** для закрепления материала

Каждая тема сопровождается примерами кода и практикой.
